# منظومة تفريغ المقابلات الصوتية واستخراج الاستمارات (Voice-to-Form AI Companion)

أداة ذكاء اصطناعي صوتية مستقلة تعمل **دون اتصال بالإنترنت 100% (Offline & Air-gapped)** وعلى المعالج العادي (CPU Only) دون الحاجة لكارت شاشة منفصل.

تقوم الأداة بالاستماع لتسجيل المقابلة أو التحقيق مع المجند المستجد، تفريغ الحديث باللغة العربية بدقة، واستخراج الحقول الأساسية وتصديرها كملف استمارة قياسي بصيغة **Markdown (`.md`)**.

---

## المزايا والخصائص
- **خفيفة جداً ومفصولة:** لا تؤثر على حجم أو سرعة برنامج `SecurityEye` الأصلي.
- **استهلاك الذاكرة:** أقل من 1.5 جيجابايت رام أثناء التفريغ (Faster-Whisper `base` أو `tiny` بنظام int8).
- **التعديل الفوري:** يمكن فتح الملف الناتج وتعديله بأي محرر نصوص (مثل Notepad المفكرة) لتصحيح أي كلمة قبل الاستيراد.
- **التوافق التام:** متوافقة 100% مع منظومة الاستيراد الذكية داخل `SecurityEye`.

---

## متطلبات التشغيل والتثبيت
1. تأكد من وجود بايثون (Python 3.10+) على الجهاز.
2. قم بتثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

---

## كيفية الاستخدام

### 1. تفريغ ملف صوتي مسجل:
```bash
python voice_to_md.py interview_01.wav
```
سيقوم البرنامج بتفريغ الصوت واستخراج الاسم، الرقم القومي، المؤهل، والملاحظات وحفظ ملف `.md` داخل مجلد `output_forms/`.

### 2. التشغيل التفاعلي السريع:
```bash
python voice_to_md.py
```
يتيح إدخال وتوليد استمارة تجريبية مباشرة.

### 3. الاستيراد في برنامج SecurityEye:
1. افتح برنامج `SecurityEye`.
2. اضغط على زر **«استيراد (.md)»** في شريط الأدوات أو تبويب الأدوات في التطبيق.
3. اسحب ملفات الـ `.md` وأفلتها في نافذة الاستيراد.
4. عاين البيانات وتأكد من حالة السجلات، ثم اضغط **«تأكيد واستيراد»**.
