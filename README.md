## 📖 نظرة عامة
منظومة أمنية متكاملة لسطح المكتب تعمل دون إنترنت (Offline 100%) ومصممة بأعلى معايير الأمان لإدارة وتسجيل وفحص مجندي مراكز التدريب، وأرشفة الصور والوثائق الرسمية، والتقاط الفيديوهات التوثيقية، مع مساعد ذكي مدمج يفهم اللهجة المصرية والاستعلامات الأمنية المعقدة، ودعم الربط الشبكي التزامني عبر شبكة الواي فاي المحلية (Local Wi-Fi LAN).

## ⚡ التشغيل السريع والإعداد على جهاز جديد

### 1. إعداد البيئة لأول مرة على أي جهاز:
عند استنساخ المشروع من GitHub لأول مرة على جهاز كمبيوتر جديد:
* انقر نقراً مزدوجاً على الملف:
  ```text
  SETUP_ENVIRONMENT.bat
  ```
  يقوم السكريبت تلقائياً بـ:
  1. التحقق من تثبيت بيئة Node.js.
  2. تثبيت جميع مكتبات وحزم المشروع (`npm install`).
  3. إنشاء شجرة المجلدات الرسمية (`data/`, `uploads/`, `assets/`).
  4. بناء واجهة المستخدم (`npm run build`).
  5. فحص جاهزية محرك ونموذج الذكاء الاصطناعي المحلي.

### 2. تشغيل المنظومة اليومي:
* انقر نقراً مزدوجاً على:
  ```text
  RUN_SYSTEM.bat
  ```
  أو:
  ```text
  تشغيل_البرنامج.bat
  ```
  *(يقوم بتشغيل التطبيق المجمّع فوراً، أو تشغيل الخادم وفتح الواجهة في نافذة سطح مكتب مخصصة).*

### 3. بناء حزمة التثبيت المستقلة للويندوز (.exe):
لبناء ملف التثبيت المكتمل `SecurityEye_VER_02.3.1_SETUP.exe`:
```bash
npm run dist
```
ينتج الملف النهائي داخل مجلد `dist-electron/`، ويكون ذاتي الاحتواء لا يحتاج أي برامج إضافية على جهاز المستخدم النهائي.

## 🗄️ مسارات تخزين البيانات والمرفقات (Data Architecture)

لحماية البيانات من الحذف أثناء ترقية أو تثبيت نسخ أحدث من المنظومة، تتبع المنظومة معايير Windows القياسية في عزل البيانات:

| العنصر | في وضع البرنامج المثبت (.exe) | في وضع التطوير والباتش (RUN_SYSTEM) |
| :--- | :--- | :--- |
| **قاعدة البيانات** | `%APPDATA%\منظومة فحص وتسجيل المجندين - SECURITY EYE\data\recruits.db` | `<مجلد_المشروع>\data\recruits.db` |
| **الصور والمرفقات** | `%APPDATA%\منظومة فحص وتسجيل المجندين - SECURITY EYE\uploads\` | `<مجلد_المشروع>\uploads\` |
| **ملف المفتاح السري** | `%APPDATA%\منظومة فحص وتسجيل المجندين - SECURITY EYE\data\jwt.secret` | `<مجلد_المشروع>\data\jwt.secret` |
| **النسخ الاحتياطية** | `%APPDATA%\منظومة فحص وتسجيل المجندين - SECURITY EYE\backups\` | `<مجلد_المشروع>\backups\` |

> [!NOTE]
> **نقل البيانات والصور لجهاز آخر:**  
> نظراً لأن GitHub يحظر رفع الصور والبيانات الشخصية للمجندين لأسباب أمنية وسرية، لنقل بياناتك الحقيقية من جهاز لآخر:  
> انقل ملف `recruits.db` ومجلد `uploads` وضعهما في المسار الموضح بالجدول أعلاه على الجهاز الجديد.

## 🧠 المساعد الذكي المحلي (Offline AI Engine)
المنظومة مزودة بنظام ذكاء اصطناعي محلي هجين يعمل بـ:
1. **نمط البحث القطعي والذكي (FTS5 Search):** يعمل فورياً وبأعلى سرعة حتى دون وجود نماذج لغوية.
2. **محرك الاستدلال اللغوي المحلي (llama.cpp Sidecar):**
   - يدعم نموذج **Qwen 2.5 0.5B Instruct** (أو Qwen 1.5B / 3B).
   - يفهم أسئلة التحقيق باللغة العربية الفصحى والعامية المصرية الدارجة (مثل: *"مين اللي عنده إصابة في دراعه؟"*, *"طلعلي اللي مسافرين برا"*).
   - لا يتطلب إنترنت ولا يخرج أي حرف خارج الجهاز المحلي (`127.0.0.1:5001`).

### تزويد ملفات الذكاء الاصطناعي:
ضع الملفات التالية داخل مجلد `assets` في المشروع:
* محرك التشغيل: `assets/runtimes/llama-server.exe` (مع ملفات الـ DLL التابعة له).
* ملف النموذج: `assets/ai/qwen2.5-0.5b-instruct-q4_k_m.gguf`.
* ثم تحقق من الجاهزية عبر:
  ```bash
  npm run verify:ai
  ```

## 🔒 الأمان وتحديثات النسخ (Security & Upgrades)

1. **الترقية الآمنة:** عند تثبيت نسخة جديدة، ثبّت النسخة الجديدة فوق القديمة مباشرة دون إزالة التثبيت القديم. المنظومة تقوم بعملية **Auto-Migration** تلقائية وتضيف أي أعمدة أو جداول جديدة دون المساس بالسجلات القديمة.
2. **تأمين المرفقات:** يُمنع استعراض صور أو فيديوهات المجندين عبر الشبكة الداخلية بدون جلسة دخول مصرح بها. يتم تجديد كوكي الوصول الأمني تلقائياً عند فتح المنظومة.
3. **النسخ الاحتياطي:** المنظومة تنشئ نسخة احتياطية دورية كل 6 ساعات في الخلفية، مع إمكانية تصدير نسخة فورية إلى فلاشة USB من خلال نافذة **"النسخ الاحتياطي"**.
