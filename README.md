# منظومة تسجيل وفحص المجندين المستجدين
**الإدارة العامة للأمن المركزي — منطقة وسط الدلتا**
**مركز تدريب المجندين — وحدة الأمن والتحريات**

---

## نظرة عامة
تطبيق سطح مكتب تنفيذي ذكي ومحلي بالكامل مصمم خصيصاً لتسجيل وفحص المجندين المستجدين وحفظ بياناتهم وصورهم الشخصية المباشرة ومقاطع الفيديو التوثيقية (30 ثانية)، مع دعم العمل الشبكي والمزامنة اللحظية عبر الواي فاي الداخلي بين أكثر من جهاز دون الحاجة لاتصال بالإنترنت.

---

## المميزات الرئيسية
1. **نمط الإدخال السريع (Kiosk POS Mode):**
   - استعراض الاستمارة الرسمية **سؤالاً بسؤال** بخط عربي عريض جداً وشاشة مركزة.
   - انتقال تلقائي وفوري للسؤال التالي بمجرد الضغط على زر **`Enter`**.
   - إمكانية الرجوع للسؤال السابق عبر `Alt + ↑` أو زر السابق.
   - فحص ذكي للرقم القومي المصري (14 رقماً) واستخراج تاريخ الميلاد والمحافظة تلقائياً.

2. **محطة الوسائط الرقمية المباشرة (Live Media Station):**
   - **التقاط الصورة الشخصية:** مباشرة عبر الويب كام مع إطار بيضاوي توجيهي بضغطة زر أو زر المسطرة (`Space`).
   - **تسجيل مقطع الفيديو 30 ثانية:** تسجيل صوت وصورة مباشر مع عداد تنازلي رقمي دائري (من 30 إلى 0 ثانية) وإيقاف تلقائي أو يدوي ومعاينة فورية.

3. **تقسيم الدفوع التجنيدية السنوية الأربعة:**
   - دفع شهر 1 (يناير).
   - دفع شهر 4 (أبريل).
   - دفع شهر 7 (يوليو).
   - دفع شهر 10 (أكتوبر).
   - إمكانية تحديد الدفع النشط بنقرة واحدة لربط كافة المجندين الجدد به تلقائياً.

4. **المزامنة والربط الشبكي عبر الواي فاي الداخلي (Local Wi-Fi Sync):**
   - عند تشغيل البرنامج على الجهاز الرئيسي، يقوم تلقائياً بفتح خادم شبكة داخلي.
   - يمكن لأي جهاز لابتوب، كمبيوتر، أو تابلت متصل بنفس الراوتر فتح الرابط المباشر أو مسح كود الـ QR والبدء في تسجيل المجندين بالتزامن في نفس قاعدة البيانات دون أي تعارض!

5. **طباعة استمارة الفحص الرسمية (A4):**
   - طباعة فورية مطابقة بنسبة 100% للاستمارة الورقية الرسمية المعتمدة لمركز تدريب المجندين بوحدة الأمن والتحريات، متضمنة صورة المجند الشخصية في موضعها وتوقيعات الفحص والاعتماد.

6. **داشبورد عصرية ومحرك بحث فوري:**
   - بحث فوري بالاسم الرباعي، الرقم القومي، المهنة، أو العنوان.
   - فلترة بالدفع التجنيدي والمؤهل الدراسي.
   - إحصائيات حية لعدد المجندين، وحضور اليوم، واكتمال الفيديوهات.

## طريقة التشغيل

### التشغيل السريع بضغطة زر واحدة:
* انقر نقراً مزدوجاً على ملف:
  ```text
  تشغيل_البرنامج.bat
  ```
  يقوم الملف تلقائياً بفحص البيئة، وتثبيت الحزم اللازمة لأول مرة، وبناء الواجهة، وتشغيل نافذة البرنامج المستقلة.

### أو عبر أوامر الطرفية (Terminal):
```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل بيئة التطوير
npm run dev

# 3. بناء الواجهة والتطبيق
npm run build

# 4. تشغيل البرنامج عبر Electron
npm run electron:start

# 5. استخراج ملف التثبيت المستقل (.exe)
npm run dist
```

---

## ربط الأجهزة الإضافية عبر الواي فاي (Wi-Fi):
1. افتح البرنامج على الجهاز الرئيسي.
2. انقر على زر **"ربط الأجهزة (Wi-Fi)"** في الشريط العلوي.
3. ستظهر لك نافذة بها الرابط المباشر (مثال: `http://192.168.1.50:5000`) وكود QR.
4. افتح الرابط من أي لابتوب آخر متصل بنفس الراوتر في المتصفح، وسيعمل النظام فوراً!
