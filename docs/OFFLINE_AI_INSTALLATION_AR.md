# دليل التثبيت والتشغيل أوفلاين لمنظومة AMN-EYE
## دليل التشغيل دون إنترنت وإعداد الذكاء الاصطناعي المحلي

---

## 1. التثبيت السريع للبرنامج المستقل (.exe)
البرنامج يأتي مجهزاً بحزمة تثبيت مدمجة ذاتية الاحتواء لا تحتاج إلى اتصال بالإنترنت أو تثبيت برامج إضافية على جهاز المستخدم النهائي.

1. انسخ ملف التثبيت:
   ```text
   SecurityEye_VER_02.3_SETUP.exe
   ```
   إلى الجهاز الرئيسي (Principal Server PC) عبر فلاشة USB.
2. انقر نقراً مزدوجاً على ملف التثبيت واتبع خطوات المعالج.
3. ستظهر أيقونة المنظومة الرسمية على سطح المكتب باسم:
   > **منظومة فحص وتسجيل المجندين - SECURITY EYE**

---

## 2. الإعداد الأمني لأول تشغيل (First-Run Security Setup)

### 2.1 بيانات الدخول الافتراضية
* **اسم المستخدم:** `admin`
* **كلمة المرور الافتراضية:** `123456`

> [!IMPORTANT]
> لأسباب أمنية صارمة، يُلزم النظام المدير بتغيير كلمة المرور الافتراضية فور تسجيل الدخول الأول، لتأمين المنظومة ضد أي دخول غير مصرح به عبر الشبكة الداخلية.

### 2.2 إنشاء كلمة مرور مشفرة مخصصة للمدير
في حال الرغبة في تعيين كلمة مرور مخصصة مسبقاً، افتح موجه الأوامر في مجلد البرنامج ونفذ:
```powershell
npm run hashpass -- "كلمة_المرور_الجديدة_هنا"
```
انسخ النص المشفر الناتج وضعه في ملف `.env` أمام:
```env
ADMIN_PASSWORD_HASH=$2b$10$...
```

---

## 3. ربط الأجهزة الإضافية عبر الواي فاي الداخلي (Local Wi-Fi LAN)
1. افتح المنظومة على الجهاز الرئيسي (Server).
2. انقر على زر **"ربط الأجهزة (Wi-Fi)"** في الشريط العلوي.
3. ستظهر نافذة بها عنوان الآي بي الداخلي (مثال: `http://192.168.1.50:5000`) وكود QR ذكي.
4. افتح المتصفح (Edge أو Chrome) من أي لابتوب أو تابلت متصل بنفس الراوتر، وافتح الرابط.
5. يمكن للمستخدمين تسجيل الدخول بالاسم وكلمة المرور أو مسح كود الـ QR للبطاقة الذكية.
6. **الأمان:** لن يتمكن أي جهاز من استعراض الصور أو مقاطع الفيديو أو الوثائق الرسمية بدون تسجيل دخول مصرح وناجح.

---

## 4. تزويد ملفات الذكاء الاصطناعي المحلي المدمج (Offline AI Provisioning)

المنظومة تعمل فورياً بنمط **البحث القطعي والذكي المتقدم (FTS5)** حتى في حالة عدم تزويد ملفات النموذج اللغوي.

لتفعيل الاستدلال اللغوي التوليدي للمساعد الذكي:
1. انسخ ملف محرك التشغيل:
   ```text
   llama-server.exe
   ```
   وضعه داخل مجلد:
   ```text
   assets/runtimes/llama-server.exe
   ```
2. انسخ ملف النموذج اللغوي المعتمد:
   ```text
   qwen3-1.7b-instruct-q4_k_m.gguf
   ```
   وضعه داخل مجلد:
   ```text
   assets/ai/qwen3-1.7b-instruct-q4_k_m.gguf
   ```
3. تحقق من سلامة الملفات عبر تشغيل:
   ```powershell
   npm run verify:ai
   ```
4. سيتولى البرنامج إدارة وتشغيل المحرك تلقائياً في الخلفية عند الحاجة وبأعلى درجات الأمان على `127.0.0.1:5001`.

---

## 5. الترقية إلى أجهزة 16GB RAM والتبديل بين النماذج
في حال ترقية جهاز الخادم إلى 16GB RAM:
1. يمكن استخدام نموذج أكبر مثل `Qwen3 4B` أو `Phi-4-mini`.
2. ضع ملف النموذج الجديد في `assets/ai/`.
3. قم بتعديل ملف الإعدادات البيئية `.env`:
   ```env
   AI_MODEL_ID=qwen3-4b-instruct-q4km
   AI_THREADS=6
   AI_CONTEXT_TOKENS=4096
   ```
4. أعد تشغيل المنظومة، وستعمل بالإعدادات المحدثة تلقائياً.

## 6. استكشاف الأخطاء وحلها (Troubleshooting)

| المشكلة | السبب المحتمل | الحل |
| :--- | :--- | :--- |
| **لا يمكن فتح الصور على الأجهزة الفرعية** | عدم وجود جلسة نشطة | تأكد من تسجيل الدخول أولاً؛ تمنع المنظومة استعراض المرفقات بدون جلسة مصرحة |
| **المساعد الذكي يذكر "نمط البحث القطعي"** | ملفات النموذج غير موجودة في `assets/` | تأكد من وجود `llama-server.exe` و `qwen3-1.7b` في مجلد `assets/` وتشغيل `npm run verify:ai` |
| **بطء الاستجابة أثناء الكتابة** | تشغيل برامج أخرى تستهلك الرام | تم ضبط النموذج ليستهلك أقل من 2GB RAM؛ تأكد من إغلاق المتصفحات الثقيلة غير المستخدمة على جهاز السيرفر |
