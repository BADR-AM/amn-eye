# منظومة AMN-EYE — هيكلية الذكاء الاصطناعي المحلي والبحث المؤمن
## Architecture Document: Embedded Offline AI & Secure Search

---

## 1. نظرة عامة (System Overview)
تم تصميم وتطوير معمارية الذكاء الاصطناعي لمنظومة **AMN-EYE (منظومة فحص وتسجيل المجندين المستجدين)** لتعمل بنسبة **100% بدون اتصال بالإنترنت (Offline-First)**، ودون الاعتماد على أي خدمات سحابية أو مفاتيح API خارجية، مع مراعاة القيود التشغيلية الصارمة على أجهزة بمعالجات Intel الجيل الثامن وذاكرة 8GB RAM بدون كارت شاشة خارجي (CPU-Only).

```
                      +------------------------------------------+
                      |         Principal Server PC              |
                      |  (Electron App + Embedded Server)        |
                      +------------------------------------------+
                                    |                |
                    127.0.0.1:5000  |                | 127.0.0.1:5001 (Internal Only)
                                    v                v
                       +----------------+      +------------------+
                       | Express Server | <--> |   llama-server   |
                       |  & SQLite DB   |      | (Local Sidecar)  |
                       +----------------+      +------------------+
                                ^
                                | Local Wi-Fi (Authenticated JWT / Cookie)
                 +--------------+--------------+
                 |                             |
                 v                             v
        [Client Laptop 1]             [Client Tablet 2]
         (Browser Only)                (Browser Only)
```

## 2. الطبقات المعمارية (Architectural Layers)

### 2.1 طبقة الأمان وعزل الشبكة (Security & Network Isolation)
1. **خادم الاستدلال (Inference Engine):**
   - يرتبط محرك `llama-server` حصرياً بعنوان الاسترجاع الداخلي `127.0.0.1:5001`.
   - لا يتم الإعلان عن منفذ النموذج مطلقاً عبر `/api/network-info` أو مشاركته على شبكة الواي فاي المحلية.
   - كافة طلبات الذكاء الاصطناعي تمر عبر خادم Express المحمي ببروتوكول التحقق من الجلسات والرموز المشفرة (JWT).
2. **حماية المرفقات (`/uploads`):**
   - تم إلغاء المسار الساكن العام غير المصرح.
   - يتطلب الوصول لأي صورة أو فيديو أو وثيقة رسمية تصريحاً أمنياً سارياً (عبر ترويسة `Authorization: Bearer`، أو كوكيز الجلسة `auth_token`، أو بارامتر الرابط `?token=`).
   - حماية ضد هجمات تجاوز المسارات (Path Traversal Protection) مع فحص الحدود الجغرافية للمجلد المصرح به.
3. **تأمين النطاقات التبادلية (CORS Hardening):**
   - تقييد الوصول للأجهزة المحلية ونطاقات الشبكة الداخلية الخاصة (`192.168.x.x`, `10.x.x.x`, `127.0.0.1`).
   - حظر أي طلبات قادمة من نطاقات أو مواقع إنترنت خارجية.

## 3. طبقة الاستعلام الهجين (Hybrid Intent Routing)
يعتمد النظام مبدأ: **"الاستعلام القطعي أولاً، والنموذج اللغوي ثانياً"**:

```
                       [ استفسار المستخدم بالعربية ]
                                     |
                                     v
                  +--------------------------------------+
                  | 1. فحص الرقم القومي المباشر (14 رقم) | ---> [ استعلام فوري بالرقم القومي ]
                  +--------------------------------------+
                                     | (غير موجود)
                                     v
                  +--------------------------------------+
                  | 2. مطابقة الكلمات المفتاحية المصرحة  | ---> [ تنفيذ استعلام معتمد ومحدد ]
                  +--------------------------------------+
                                     | (غير متطابق)
                                     v
                  +--------------------------------------+
                  | 3. التخطيط الذكي بالنموذج (JSON)    | ---> [ التحقق من المخطط intentSchema ]
                  +--------------------------------------+
                                     | (فشل / غير متوفر)
                                     v
                  +--------------------------------------+
                  | 4. محرك البحث النصي الكامل (FTS5)     | ---> [ استخراج السجلات المرتبة ]
                  +--------------------------------------+
```

### 3.1 كتالوج الاستعلامات المعتمدة (`queryCatalog.js`)
- لا يُسمح بتنفيذ أي كود SQL حر أو ديناميكي ناتج عن النموذج اللغوي.
- كافة العمليات تتم عبر استعلامات معيارية مسبقة الفحص والاعتماد (Read-Only)، مع تقييد أقصى لعدد السجلات (Max 50 Rows) لحماية الذاكرة العشوائية.

### 3.2 معالجة وتطبيع اللغة العربية (`arabicNormalize.js`)
- توحيد همزات الألف (`أ`, `إ`, `آ`, `ٱ` -> `ا`).
- توحيد التاء المربوطة (`ة` -> `ه`) والياء (`ى` -> `ي`).
- إزالة التشكيل وحركات الإعراب والتطويل (`ـ`).
- تحويل الأرقام المشرقية والفارسية (`٠١٢٣٤٥٦٧٨٩`) إلى الأرقام القياسية.
- تشييد عبارات بحث آمنة وخالية من ثغرات الحقن لمحرك `SQLite FTS5`.

## 4. المحرك اللغوي المدمج (Local Sidecar Inference)
- **المحرك:** `llama.cpp` (نسخة `llama-server.exe` المجمعة لويندوز x64).
- **النموذج الافتراضي:** `Qwen3 1.7B Instruct (GGUF Q4_K_M)`.
- **حدود العتاد:**
  - عدد خيوط المعالجة: 4 Threads (مناسبة لمعالجات Intel Core i3/i5/i7 الجيل الثامن).
  - الحد الأقصى للسياق: 2048 Tokens.
  - الحد الأقصى للمخرجات: 256 Tokens.
  - الحد الأقصى للتوليد المتزامن: 1 عملية توليد واحدة، مع طابور انتظار بحد أقصى 4 طلبات.
  - سياسة التشغيل: تحميل كسول (Lazy Loading) عند أول طلب لتوفير الذاكرة العشوائية.
